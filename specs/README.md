# Specs

What the game does, one file per area. `TEMPLATE.md` is the starting point for a
new one, and `CLAUDE.md` in the repo root describes the flow.

Specs are numbered in the order they were written. The number is an identifier,
not a priority, and it never changes once a spec exists.

| Spec | Covers |
| --- | --- |
| [0001](0001-playfield.md) | The cell grid, the border, and resizing |
| [0002](0002-snake.md) | Movement, turning, growth, and crashes |
| [0003](0003-pellets.md) | Pellets, scoring, and speeding up |
| [0004](0004-game-flow.md) | Menu, runs, and game over |
| [0005](0005-a-picture-of-a-run.md) | The staged run held against a picture of it, with the pellet given a place so two runs agree |
